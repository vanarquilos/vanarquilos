### Build Taste

- Local-first when accounts or cloud do not make the product better.
- Clear copy, real states, useful defaults, and calm visual hierarchy.
- No fake AI, fake OCR, fake cloud, fake usage numbers, or unsupported launch claims.
- Small APIs, readable docs, stable workflows, and reviewable changes.
