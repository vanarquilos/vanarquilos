## Build Principles

- Local-first by default when the product does not need accounts or cloud.
- No fake AI, fake OCR, fake cloud, fake user counts, or unsupported launch claims.
- Small APIs, clear names, and documentation that explains real boundaries.
- Premium UI through spacing, contrast, typography, and restraint.
- Ship in safe batches: read the codebase, preserve decisions, test what changed, then document the risk.
